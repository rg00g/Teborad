# 🎯 Teborad - منصة إدارة المشاريع الاحترافية

منصة متكاملة لإدارة المشاريع والتواصل بين الفريق مع واجهة احترافية مشابهة لـ Discord.

## ✨ الميزات الرئيسية

### 👤 نظام المستخدمين والمشاريع
- تسجيل دخول ذو صلاحيات متعددة (مشرف، مستخدم عادي)
- إنشاء حسابات للمستخدمين الجدد
- نظام الانضمام للمشاريع مع موافقة المشرفين
- صور البروفايل الدائرية

### 💬 نظام الرسائل
- **رسائل هامة**: للمشرفين فقط، تفاعلات بالإيموجي والملصقات
- **رسائل عامة**: للجميع مع المنشن والسحب والتصوير والصور والرسائل الصوتية (حد أقصى دقيقة واحدة)
- **رسائل خاصة**: بين المستخدمين
- تحديثات مزامنة فوري مع animations

### 📋 نظام المهمات
- إنشاء مهمات عامة أو خاصة
- تحديد التواريخ والمواعيد النهائية
- إرفاق ملفات أو نصوص
- عرض المهمات المكتملة
- شعارات/صور للمهمات

### ⚙️ الإعدادات المتقدمة
- تعديل اسم المشروع والنبذة
- تغيير الخلفيات والصور الرئيسية
- نمط مظهر (Dark/Light Mode)
- إدارة المستخدمين والصلاحيات

## 🛠️ التكنولوجيا المستخدمة
- **Frontend**: React.js, Tailwind CSS, Framer Motion
- **Backend**: Node.js, Express.js
- **Database**: MongoDB/PostgreSQL
- **Real-time**: Socket.io
- **Storage**: Multer (للملفات)
- **Authentication**: JWT

## 📁 هيكل المشروع
```
Teborad/
├── frontend/          # واجهة المستخدم
├── backend/           # خادم الويب
├── database/          # ملفات قاعدة البيانات
└── docs/              # التوثيق
```
